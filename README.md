# Notas

Repositorio centralizado de notas técnicas sobre distintos temas de ingeniería de software. Cada sección es una referencia de estudio concisa y práctica.

## Índice

### [Frontend](./frontend/README.md)

Conceptos avanzados de desarrollo frontend, preparación para entrevistas técnicas y fundamentos de JavaScript/React/TypeScript.

### [SEO](./seo/README.md)

Guía completa de SEO: fundamentos, Core Web Vitals, elementos técnicos y checklist de optimización.

### [Ciberseguridad](./ciberseguridad/README.md)

Seguridad en desarrollo de software: vulnerabilidades, sistemas de identificación (CVE/CWE/CVSS), Zero Trust, gestión de dependencias, compliance y estándares.

### [Criptografía](./criptografia/README.md)

Criptografía aplicada: cifrado simétrico/asimétrico, funciones hash, TLS, y patrones de seguridad web.
